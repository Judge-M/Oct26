## Defects found and remediation in this change

1. **Wazuh access missing from private handout — high.** The authored route told participants to use a supplied read-only account, but registration returned only IRIS, CTFd, and Guacamole credentials. The worker now adds the runtime `wazuh_reader` account to the private retrieval record and the handout displays its trusted URL and credentials. Nothing is added to public registration state or source control.
2. **No CSV/text viewer — high.** Double-clicking a CSV opened an empty “Set Default Application” dialog. The desktop now installs Mousepad and assigns it to plain text, CSV, and JSON.
3. **Missing static-analysis utilities — high.** T17/T18 required a fallback because `strings`, `readelf`, and `file` were absent. The image now installs `binutils` and `file`, validates the commands at build time, and exercises them in the container smoke test.
4. **Ordinary guidance disclosed answers — high content issue.** T01-Q1 and T07 supplements contained literal solution values before the paid walkthrough. Ordinary guidance now teaches the correlation path without disclosing those values. The explicit final walkthrough remains an intentional 75%-cost answer reveal.
5. **Incorrect question-level sources — medium/high.** T07-Q1 cited `session_refresh` for a password-reset question; T07-Q2/Q4 and T12-Q2/Q3 also cited ticket-level records that did not contain the requested fact. Question-level source and selection metadata now point to the evidence that actually answers each question.
6. **T13-Q2 answer granularity — medium.** The prompt asked for an executable but rejected the full path while accepting a basename. It now explicitly asks for the parent executable basename and supplies filename-only formatting guidance.

## Improvements implemented after the rehearsal

1. **Team-local midpoint operational update.** After T01–T10 are complete, Faye Maxwell's scope-expansion brief appears prominently for that team. It explains the new priorities and may be dismissed once per team/browser. Evidence release remains automatic and team-local.
2. **Guacamole root redirect.** The public hostname now sends `/` to `/guacamole/`, eliminating the misleading root-page failure while preserving the standard Guacamole application path.
3. **Readable, durable activity clock.** Participant pages display `HH:MM:SS`; after all tickets complete, the clock freezes at the durable final-assessment timestamp and shows `(complete)` even while the overall exercise remains in running mode.
4. **Verified IRIS chronology.** The shared participant view now grows a source-cited incident timeline as supporting tickets complete. It distinguishes incident UTC from participant submission time and never publishes an event before its supporting ticket is complete.
5. **T13–T16 correlation board.** The prepared-record stretch now includes a browser-local process-to-network relationship board for parent executable/PID, viewer PID, cache argument, remote endpoint, limitation, and a cross-record review check. T16 guidance explicitly requires the multi-source join.
6. **T20 capstone workspace.** Before the final four submissions, participants receive a browser-local structured assessment workspace for confirmed facts, unestablished claims, unresolved questions, recommended action, and citation review. T20 guidance explicitly directs them to synthesize the assessment rather than answer four isolated prompts.

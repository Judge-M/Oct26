## Pace sensitivity

The authored 65-minute ticket allowance is unmeasured. This table rescales it to show how beginner pace moves the investigation makespan and the event total.

| Pace multiplier | Investigation makespan | Event total | Fits 240-300 |
|---|---|---|---|
| 1.00x | 195 | 275 | yes |
| 1.25x | 243 | 323 | NO |
| 1.50x | 294 | 374 | NO |
| 1.75x | 342 | 422 | NO |
| 2.00x | 390 | 470 | NO |

Reading: below 1.0x the event runs short (facilitated segments pad it); above ~1.4x the investigation block alone consumes the window and the agenda must shed facilitated time or accept overrun. The honest fix for a durable gap is more authored content (separate small content tasks), not agenda padding.

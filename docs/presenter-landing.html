Commands actually typed during play

From event-day-commands.md §3–§7. event-profile.json and R are your profile and private runtime directory.

  • status python -m ridge.deploy status --profile event-profile.json --runtime R
  • up python -m ridge.deploy up --teams 10 --profile event-profile.json --runtime R
  • start python -m ridge.deploy start --profile event-profile.json --runtime R
  • pause python -m ridge.deploy pause --profile event-profile.json --runtime R
  • announce python -m ridge.cli announce --operator EXCON --text "..."
  • recover python -m ridge.cli recover T03 --generation 1 --operator EXCON --reason "..."
  • backup python -m ridge.deploy backup --profile event-profile.json --runtime R

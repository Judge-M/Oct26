# Cue and release boundaries

There are exactly two narrative cues:

| Cue | Condition | Evidence effect |
|---|---|---|
| Introduction | Teams assembled, before investigation | None |
| Final assessment | 20/20 stages complete and final assessment published | None; it narrates findings already visible |

The conclusion must follow the automatic final-assessment publication. It is not a midpoint inject, evidence release or substitute answer key.

There is no approved post-lunch cue, three-brief structure, seven-brief structure, generic end-of-time handover or prerecorded evidence-release announcement in this package. Evidence-release mechanics remain governed by [the facilitator evidence-release runbook](../../facilitator-evidence-release.md).

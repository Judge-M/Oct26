## Implement

Define one authoritative active-site generation and implement a practical fencing mechanism. A planned move must disable source writes/network access before destination activation. A partitioned/unreachable source requires externally verifiable fencing, not a flag only written at the destination. Ensure all mutation paths and resumed workers respect the chosen generation/activation contract.

## Acceptance checks

Two simulated sites cannot accept mutations for the same active generation. Stale worker restart is fenced. Partial switch cannot unpause both sites. Test coordinator crash before/after fencing and restore a safe paused state. Document where the authority lives if the central host is lost.

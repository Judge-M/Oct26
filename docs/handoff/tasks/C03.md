## Implement

Implement one provider-independent delivery contract. Recommended first implementation: a service on each desktop fetches a checksum manifest and new files from a private controller endpoint into root-owned staging, validates them, and atomically publishes read-only files. Keep originals/template immutable. Report release generation and lag per desktop; reconnect catches up. Define which follow-ups require file manager/Wazuh rather than Autopsy indexing.

## Acceptance checks

Unlock T07/T09/T11/T19 in real services and verify expected files/index rows on every required desktop. Interrupt a transfer: no truncated visible file; retry converges without duplicates. A disconnected desktop is marked unready/lagging and catches up before claiming readiness. Participants cannot write the share or obtain controller credentials.

## Do not expand scope

Do not mount SQLite or writable Autopsy databases over network shares. Do not invent automatic Autopsy ingest.
